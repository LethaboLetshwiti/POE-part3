# POE Part 3

This repository contains the project files for the POE Part 3 assignment. The main project content is packaged as a website archive and is ready to be extracted and run locally.

## Project Overview

The repository includes:

- `README.md` – project information and setup instructions
- `website (3).zip` – the website project files packaged as a zip archive

## How to Run the Website

1. Download or clone this repository.
2. Extract the file named `website (3).zip` to a folder on your computer.
3. Open the extracted project folder.
4. Open the `index.html` file in a browser, or serve the project locally using a simple web server.

Example local server command:

```bash
cd extracted-folder
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
