# POE Part 3

This repository contains the project files for the POE Part 3 assignment. The project is a front-end website built using HTML, CSS, and JavaScript. It is packaged as a website archive and is ready to be extracted and run locally.

## Project Overview

This project includes:

- `README.md` – project information and setup instructions
- `website (3).zip` – the website project files packaged as a zip archive
- Front-end web pages created with JavaScript for interactivity

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Website

1. Download or clone this repository.
2. Extract the file named `website (3).zip` to a folder on your computer.
3. Open the extracted project folder.
4. Open the `index.html` file directly in a browser, or run a local web server.

### Option 1: Open directly in the browser

Double-click the `index.html` file or open it in your browser.

### Option 2: Run a local JavaScript-based web server

If you have Node.js installed, you can serve the project locally:

```bash
cd extracted-folder
npx serve .
```

Then open:

```text
http://localhost:3000
```

If you do not have Node.js installed, you can also open the `index.html` file directly in a browser.
