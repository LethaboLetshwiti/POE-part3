# POE Part 3

## Project Overview

This repository contains the project files for the POE Part 3 assignment. The project is a front-end website developed using HTML, CSS, and JavaScript. It is packaged as a compressed website archive and is prepared for local extraction and execution.

The repository includes the following key items:

- `README.md` – project information and setup instructions
- `website (3).zip` – the complete website project packaged as a ZIP archive

## Objective

The purpose of this project is to demonstrate front-end web development skills through the design and implementation of a functional website. The website is intended to be opened in a browser and can be run locally without the need for a complex server environment.

## Technologies Used

- HTML
- CSS
- JavaScript

## Running the Website

To run the project locally, follow the steps below:

1. Download or clone this repository to your local machine.
2. Extract the file named `website (3).zip` into a folder of your choice.
3. Open the extracted project folder.
4. Launch the website by opening `index.html` in a browser, or by serving the project from a local web server.

### Option 1: Open Directly in a Browser

Open the `index.html` file in a browser of your choice.

### Option 2: Run a Local Web Server

If Node.js is installed, the project can be served locally using the following command:

```bash
cd extracted-folder
npx serve .
```

Then open the following URL in the browser:

```text
http://localhost:3000
```
